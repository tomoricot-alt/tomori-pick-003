# TOMORI PICK 使い方ガイド

**迷ったら、回そう。** — 選択肢の中から、ルーレットで1つを決めるアプリです。
ログインも料金も不要です。

## 1. 基本の使い方

1. 画面上部のルーレットに、いまの選択肢が表示されます。
2. オレンジの **「回す」** ボタンを押します。
3. ルーレットが回り、止まったところ（上の▼の位置）の選択肢が **結果** として大きく表示されます。
4. もう一度決めたいときは **「もう一度回す」** を押します。

どの選択肢も、選ばれる確率はまったく同じです。

## 2. 選択肢を変える

画面の下の「選択肢」で編集できます。

| 操作 | 方法 |
| --- | --- |
| 追加 | 入力欄に書いて **追加**（またはEnterキー） |
| 編集 | 項目の **編集** → 書き換えて **保存** |
| 削除 | 項目の **削除** |

ルールは次のとおりです。

- 選択肢は **2個〜12個**
- 1つあたり **20文字まで**
- 空欄はNG
- 同じ名前はNG（「ＡＢＣ」と「abc」のように、全角/半角・大文字/小文字だけが違うものも同じ扱い）
- ルーレットが回っている間は、編集できません

変更した内容は自動で保存され、アプリを閉じても残ります。

## 3. 結果をコピーする

結果の下の **「結果をコピー」** を押すと、選ばれた選択肢がクリップボードにコピーされます。メッセージアプリなどに貼り付けて使えます。

## 4. 抽選履歴

ページの下部に、最近の結果が **新しい順に最大20回分** 残ります（日時つき）。

- 1件だけ消す: その行の **削除**
- すべて消す: **履歴をすべて削除** → 確認で **削除する**

古い履歴は、21回目以降に自動で消えます。

## 5. こんな場面で

- 今日のランチ・休日の行き先を決める
- 仕事のアイデアを選ぶ
- チームの役割分担を決める
- 日常の小さな迷いを解消する

## 6. iPhoneのホーム画面に追加する

Safari で開き、共有ボタン →「ホーム画面に追加」で、アプリのように使えます。

## 7. 動きが苦手な方へ

iPhone の「動作を減らす」（設定 → アクセシビリティ → 動作）や、PCの「アニメーションを減らす」設定がオンの場合、ルーレットは回転せず、すぐに結果が表示されます。

## 8. よくある質問

**Q. データはどこに保存されますか？**
お使いの端末（ブラウザ）の中だけです。サーバーには送信されません。ブラウザのサイトデータを消去すると、選択肢と履歴も消えます。

**Q. 別の端末と共有できますか？**
いまのバージョンでは、端末ごとの保存です。

**Q. 同じ選択肢が続けて選ばれることがあります。**
毎回、独立して公平に抽選しているため、同じものが続くことも自然に起こります。
